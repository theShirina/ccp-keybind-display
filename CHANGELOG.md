# Changelog

## 0.3.1 — 2026-08-06

- Individual binding checkboxes now work after Show All Assigned has been enabled.
- Role buttons filter the settings list without changing HUD selections.
- The card background toggle now handles Vanilla checkbox values correctly.
- Removed the Preferred width control; the HUD width now follows its content.

## 0.3.0 — 2026-08-06

First public release.

- Compact, auto-fitting command and keybind display.
- Persistent Show All Assigned mode.
- Role and per-command visibility controls.
- Built-in keybind manager with conflict confirmation and rollback on failure.
- Movable minimap button and settings window.
- Migration checks, Lua 5.0.3 tests, and deterministic release builds.
