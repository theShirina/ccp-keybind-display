# Changelog

## 0.3.0 — 2026-08-06

First public release.

- Compact, auto-fitting command and keybind display.
- Persistent Show All Assigned mode.
- Role and per-command visibility controls.
- Built-in keybind manager with conflict confirmation and rollback on failure.
- Movable minimap button and settings window.
- Migration checks, Lua 5.0.3 tests, and deterministic release builds.
