# CCP Keybind Display change log

## 0.3.1 — 2026-08-06

### Changed

- Role buttons now filter the settings list without changing HUD selections.
- The HUD width now follows its text and font size; the **Preferred width** control has been removed.

### Fixed

- Individual binding checkboxes now work after **Show all assigned** has been enabled.
- The card background and HUD visibility controls now handle WoW 1.12 checkbox values correctly.

## 0.3.0 — 2026-08-06

First public release.

### Added

- Compact, auto-fitting command and keybind display.
- Persistent **Show all assigned** mode, role filters, and per-command visibility controls.
- Built-in keybind manager with conflict confirmation and rollback on failure.
- Movable minimap button and settings window.
