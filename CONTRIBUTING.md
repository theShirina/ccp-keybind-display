# Contributing

Bug reports and focused pull requests are welcome.

## Before opening a pull request

1. Keep the addon compatible with WoW 1.12.1, Interface 11200, and Lua 5.0.
2. Do not add a fixed list of CCP commands. Discovery must continue to use WoW's binding registry.
3. Do not copy or modify CCP source files in this repository.
4. Add or update a harness when behavior changes.
5. Run the validator described in the README.

Please keep changes small and explain the user-facing effect. Include screenshots for layout changes.
